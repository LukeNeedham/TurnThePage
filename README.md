# Листай / Turn the Page

Android-читалка с физически правдоподобной моделью настоящей книги.

Текущая версия: **0.8** (`versionCode = 8`). Версия задаётся централизованно
свойствами `listai.versionName` и `listai.versionCode` в `gradle.properties`.

## Текущее состояние

Реализованы этапы 0–8 — технический фундамент, физический `BookView`,
адаптация к размеру окна/Fold posture, FB2 pipeline, пагинация, bitmap-кэш,
библиотека, постоянный прогресс, управление внутри бумажной книги и сноски:

- Kotlin и Jetpack Compose;
- `applicationId = com.avstaim.listai`;
- Android API 26–36;
- английская default-локализация и русская локализация;
- debug pseudolocales;
- модульные границы parser → model → pagination → rendering → UI;
- fake `BookDocument` на 32 детерминированных блока;
- единый Canvas `BookView` без Pager;
- single page и two-page spread с мягким корешком;
- чистая бумага без синтетической «грязи», мягкое освещение и толщина стопок;
- независимая геометрия curl для forward/backward с lower-corner, edge и free anchors;
- захват с любой точки листа, возврат жеста, flick/tap completion и settle-анимации;
- 12-полосная curl-band, отдельные cast/contact shadows и подготовленные PageSurface;
- контент оборота приклеен affine-преобразованием к листу с первого кадра, без fade;
- `:core:adaptive` с AndroidX Window `1.5.1`, нейтральной моделью posture и
  lifecycle-aware `WindowInfoTracker` provider;
- автоматический single/spread по фактическим constraints, density и fold/hinge bounds;
- hinge-safe размещение: корешок совпадает с вертикальным hinge, а бумага не попадает
  под separating/occluding область;
- resize и переход single ↔ spread сохраняют текущий смысловой лист;
- unit, Compose instrumentation, screenshot и macrobenchmark scaffolds;
- CI для build/test/lint/golden validation;
- потоковый namespace-aware SAX parser для `.fb2` и `.fb2.zip`;
- формат-независимый `BookDocument` с метаданными, семантическими блоками,
  иерархическим оглавлением, сносками, anchors и типизированными ссылками;
- отложенное декодирование FB2 `<binary>` с кешированием результата;
- ограничения размера XML/ZIP/binary, запрет DTD/external entities и типизированные ошибки;
- встроенный FB2 fixture для parser- и renderer-регрессий;
- детерминированная инкрементальная пагинация на фоновом dispatcher;
- переносы строк/слов, абзацные отступы, заголовки, rich text, стихи, цитаты и изображения;
- сохранение `BookLocation` при fullscreen, resize, повороте и single ↔ spread;
- реальный русский FB2 «Атлас тихих страниц» в основном ридере;
- фоновая растеризация текста/иллюстраций в поверхности страниц, без text layout в curl;
- LRU-кэш поверхностей с лимитом 64 МиБ, закреплённые соседи и направленный prefetch;
- отмена устаревшей подготовки при смене окна/направления, очистка по memory pressure;
- лёгкий индекс страниц без удержания `StaticLayout` и декодированных bitmap всей книги;
- доступный для TalkBack текст видимых страниц наряду с bitmap-отрисовкой;
- импорт FB2/FB2.ZIP через системный выбор файла, «Открыть с помощью» и «Поделиться»;
- собственная копия в private storage; удаление из библиотеки сохраняет исходник;
- Room 2.8.4 для книг, семантического прогресса, положения обложки и закладок;
- DataStore 1.2.1 для последней книги, одноразовой инициализации и настроек чтения;
- матовый сине-серый книжный шкаф с настоящими обложками и последними открытыми книгами;
- закладки: добавить на текущей странице, перейти к сохранённому месту, удалить;
- восстановление выбранной книги, обложки, оглавления и `BookLocation` после завершения процесса;
- постоянный fullscreen на шкафе и книге; экран остаётся включённым при активном чтении;
- бумажная вкладка по центральному тапу: настройки, оглавление, закладки и переход по книге;
- только размер текста и светлая/тёмная/системная тема; по умолчанию всегда светлая;
- физические листы оглавления в общей последовательности curl, без изменения исходных anchors;
- закладки-полоски, линейка с предварительным выбором, точным процентом/страницей и подтверждением.

Доработки этапа 7.1: общий прогресс на самом листе, четыре небольших действия
в пространстве вокруг камеры, единая центральная зона тапа на всём развороте,
перекомпонованная бумажная вкладка и предметные переходы между книгой и её местом
на полке. Обложка рисуется общим painter для полки, полёта и ридера.

Уточнения этапа 7.2: прогресс — ряд точек под номером страницы, без процентов;
четыре действия напечатаны на верхнем поле бумаги, без полосы над книгой.
Оглавление имеет книжную вёрстку с точечными линиями, настоящими номерами страниц
и просторными нажимаемыми строками.

Этап 7.2.1: тап по номеру открывает «Найти место»; оглавление, закладки и точный
переход используют физическое перелистывание с сохранением места после завершения.
После визуальной корректировки оригинальная обложка заполняет весь переплёт:
без цветных полей и обрезки названия, с лёгкой тенью у корешка. Изображение
растягивается по двум осям; пропорции широких исходников меняются заметнее.
Оборот и тонкий торец — нейтральный матовый графит. Подробнее:
[обложка без полей](docs/cover-full-bleed-task.md).

Жест можно начать в любой точке страницы: вправо/влево выбирается направление,
а внешний край следует за точным смещением пальца без стартового скачка.
Верхний corner curl согласно границам v1 не реализуется. Основной ридер получает
настоящие `PageLayout`; демо сохранено для регрессионных тестов графики.
Текущий лист и соседи готовятся до разрешения соответствующего перелистывания;
активный жест использует неизменный снимок поверхностей. Запись прогресса происходит
после успешного settle и при уходе приложения в background, вне кадров curl.

## Импорт и библиотека

На книжном шкафу нажмите небольшой «+» и выберите FB2 или ZIP.
Источник копируется и разбирается в фоне; импорт можно отменить. Нажатие обложки
открывает сохранённое место, удержание обложки вызывает подтверждение удаления.
Недавно открытые книги стоят первыми.

В книге коротко коснитесь центра всего экрана, включая сгиб, чтобы достать бумажную вкладку. Движение пальца
из той же области перелистывает лист; внешние области работают как перелистывающие
тапы. На вкладке доступны размер текста, оформление, закладки, оглавление и линейка
перехода. Выбор линейкой или точным процентом/страницей не меняет место до подтверждения.
Тап вне вкладки или Back закрывает её. В верхнем поле находятся возврат на полку,
оглавление, светлая/тёмная тема и закладки. Размер текста остаётся внутри вкладки.
Вернуть книгу на полку можно верхним действием, через вкладку или тапом по пустому
пространству вокруг закрытой передней/задней обложки. Тап по внешней задней обложке
также возвращает на полку; после явного возврата повторный запуск открывает шкаф.
Открытие и возврат перемещают саму книгу с раскрытием/закрытием жёсткой обложки;
промежуточная поза анимации не переписывает сохранённое место чтения.

Одинаковый FB2 и ZIP с тем же XML имеют один SHA-256 `BookId`: повторный импорт
не сбрасывает прогресс и закладки. Для ZIP с несколькими FB2 выбирается первый
лексикографический путь, как в существующем parser. Импорт ограничен 128 МиБ
исходника; parser дополнительно ограничивает XML, распаковку и binary.

На первом запуске «Атлас тихих страниц» импортируется тем же путём и открывается
как стартовая книга. После удаления он не появляется заново. Backup и telemetry
выключены; внешняя копия не удаляется и не изменяется.

Утверждённые границы управления описаны в [плане этапа 7](docs/stage7-plan.md),
результаты реализации и проверки — в [задаче этапа 7](docs/stage7-task.md).
Уточнения и проверка исправлений — в [задаче этапа 7.1](docs/stage7.1-task.md).
Доработка бумажного управления и оглавления — в [задаче этапа 7.2](docs/stage7.2-task.md).
Перелистывание при навигации и цельная обложка — в [задаче этапа 7.2.1](docs/stage7.2.1-task.md).

Этап 8: короткие сноски печатаются внизу своего листа; длинные получают фрагмент
с продолжением. Полный текст находится в непрерывном разделе «Примечания» в конце
книги. Тап по вызову или нижнему тексту перелистывает к примечанию, печатная отметка
возврата и Android Back — к точному месту вызова, не сбивая прогресс. Раздел и пункт
оглавления отсутствуют в книгах без примечаний. Доработаны тени, корешок и стопки.
[План этапа 8](docs/stage8-plan.md) · [реализация и проверки](docs/stage8-task.md).

## Команды

Для сборки нужны Android Studio или Android SDK с API 36 и JDK 17 или новее.
После клонирования репозитория запустите из его корня:

```bash
./gradlew assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`.

Основные проверки проекта:

```bash
./gradlew assembleDebug
./gradlew assembleRelease
./gradlew test
./gradlew :core:adaptive:test
./gradlew :reader:pagination:test
./gradlew lintRelease
./gradlew :feature:reader:validateDebugScreenshotTest
./gradlew :feature:library:validateDebugScreenshotTest
./gradlew :benchmark:assemble
./gradlew :app:assembleDebugAndroidTest :feature:reader:assembleDebugAndroidTest :core:files:assembleDebugAndroidTest :core:database:assembleDebugAndroidTest
```

Instrumentation tests требуют запущенного устройства или эмулятора:

```bash
./gradlew connectedDebugAndroidTest
```

Обновление screenshot-эталонов выполняется только после визуальной проверки:

```bash
./gradlew :feature:reader:updateDebugScreenshotTest :feature:library:updateDebugScreenshotTest
```

## Архитектура

```text
:format:fb2 ──► :core:model ──► :reader:pagination ──► :reader:rendering
                                                           │
                                                           ▼
                                                   :feature:reader
                                                           │
:core:files ─┬─► :feature:library                          │
:core:database┘             └───────────────────────────────┴─► :app
:core:adaptive ───────────────────────► :feature:reader ─────┘
```

`:app` владеет application-lifetime `LibraryController`; `:core:files` копирует,
разбирает и открывает книги, а `:core:database` хранит Room schema и DataStore.
Контроллер передаёт выбранный `BookDocument` и `ReadingProgress` в `ReaderScreen`.
`:reader:pagination` остаётся чистым Kotlin; Android `StaticLayout` и декодирование
изображений изолированы адаптером `BlockMeasurer` в `:feature:reader`.

`BookDocument` содержит исходные смысловые блоки, но не страницы. Границы страниц
принадлежат `:reader:pagination`. Mapper fake-блоков в демо-страницы используется
только старым графическим демо и его регрессионными тестами.

Чистая curl-геометрия находится в `:reader:rendering`: она принимает положение
пальца и возвращает constrained pointer, линию сгиба, лицевой остаток страницы,
отражённый оборот, affine-преобразования контента и нормализованную высоту листа.
`PageCurlBandGeometryEngine` разбивает узкую область сгиба на 12 непрерывных полос.
Compose отвечает только за ввод, settle-анимацию и Canvas-отрисовку.

`:core:adaptive` изолирует AndroidX Window от ридера. `MainActivity` создаёт
`WindowManagerDevicePostureProvider`, а `:feature:reader` получает только
`DevicePosture`. Размер книги рассчитывается по фактическому Compose viewport;
fold/hinge переводится из координат окна в локальные координаты Canvas и участвует
в выборе single/spread и безопасном размещении листов.

Для этапа 7 доступен Android 36 эмулятор. Точные результаты runtime-проверок
приведены в [задаче этапа 7](docs/stage7-task.md); аппаратный Fold остаётся отдельной
площадкой проверки. JVM-тесты покрывают семантическую навигацию и сохранность копий,
instrumentation — Room v1→v2, DataStore reopen, импорт, закладки, fullscreen,
удержание экрана и возврат на полку.
