# Листай 1.2 — реализация и проверка

Дата: 2026-09-28. Локальный кандидат `1.2-rc1`, versionCode `16`.
Рабочая ветка: `codex/v1.2`; production-код зафиксирован в `f7952c3`.
Реализация и проверка завершены. Push, теги, публикация и удалённый CI
не выполнялись.

## Реализованный объём

| Требование | Результат |
| --- | --- |
| Поиск | Нижняя лупа и новый свайп вниз от верхней границы полки; поиск по названию, авторам и серии во всей библиотеке, включая стопки; нормализация регистра, пробелов и е/ё; возврат к запросу и исходной стопке. Поиска внутри книги нет. |
| Часы | Небольшая надпись в существующих элементах чтения, выключатель в настройках, системный формат времени. Receiver активен только при видимом чтении и STARTED lifecycle. Время не входит в ключ пагинации. |
| Описание | Заголовок «Описание» / «Description», белая бумага на телефоне и Fold; меню на внутренней обложке разворота. Самостоятельный сохраняемый anchor. |
| Титул | Белая страница с названием, авторами и общим векторным орнаментом. Порядок: обложка → описание → титул → текст; пустое описание пропускается. Оглавление доступно отдельным переходом с возвратом в исходное состояние. |
| Главы | Семантические начала глав с новой страницы, номером и векторным украшением. Обе ветки пагинации, в том числе сноски; исходные IDs/UTF-16 offsets сохраняются. Подзаголовки и названия частей не превращаются в главы. |
| Масштаб | Три уровня pinch; MEDIUM сохраняет геометрию 1.1. DataStore сохраняет выбор; контексты полки и стопок хранят видимый предмет. |
| Стопки | Создание перетаскиванием с задержкой и через меню, раскрытие, переименование, добавление/извлечение/перенос/перестановка книг, разбор и Undo. Одна книга остаётся стопкой; пустая стопка удаляется. Отмена меняет размещение, не откатывает прогресс/импорт и не воскрешает удалённую книгу. |
| Кот | Оригинальная векторная графика по фотографии пользователя. Пять коротких касаний одной свободной области за три секунды; появление, сон, реакция и хвост. Спящий кот статичен; скрытый и остановленный экран не продолжает анимацию. |

Новая вёрстка применяется к FB2/EPUB. PDF сохраняет исходные страницы и anchors.
Явный титул EPUB показывается один раз, включая редкую книгу без основного текста.
Legacy anchor исходного титула нормализуется до первого сохранения состояния.

## Организация работы

Root и три субагента работали параллельно в согласованных областях:

- A: каталог, Room v5, DataStore, миграции, операции стопок, Undo, backfill и кот.
- B: поиск, масштаб, стопки, единый ввод и взаимодействия библиотеки.
- C: FB2/EPUB, семантика глав, пагинация, белые страницы, часы и anchors ридера.
- Root: общие контракты, связь с приложением, интеграционные проверки, визуальный
  осмотр, Git-коммиты и подписанная сборка.

Логические изменения фиксировались отдельными коммитами. Все Git-изменения
выполнял root; субагенты передавали проверяемые пакеты без независимого push.

## Проверки

Основная команда полного host gate:

```bash
./gradlew test lintRelease :app:assembleDebug \
  :feature:reader:validateDebugScreenshotTest \
  :feature:library:validateDebugScreenshotTest
```

Финальный полный gate прошёл на итоговом production-коде: **BUILD SUCCESSFUL**,
лог `out/qa/v1.2/logs/final-acceptance-host-gate.log` (2 мин 57 с).
Результат: **361 JVM-тест, 158 скриншотов ридера и 31 скриншот библиотеки**,
все без ошибок; lintRelease и assembleDebug также прошли. Эталоны менялись после осмотра actual/diff; средний масштаб
сверен с прежней геометрией. Матрица включает телефон/Fold, RU/EN, обе темы,
крупный шрифт, длинные заголовки, описание, титул, начало главы и позы кота.

Instrumentation запускалась на временных AVD API 26 и API 36. Указанные ниже
прогоны выполнялись непосредственно через `am instrument` с класс-фильтрами,
после сборки `assembleDebugAndroidTest` и установки APK:

| Набор | Содержание | Лог |
| --- | --- | --- |

Реальные часы на API 36 прошли смену минуты, 12→24, часовых поясов UTC/Гонолулу/Токио,
выключение и возвращение из фона. Во всех шести контрольных точках:
`ReaderSurfaceRenders=2`, anchor `clock-text:24:24`, прежняя идентичность
пагинации. Регистрация TIME_TICK подтверждена системным dumpsys: 1→0→1.
Evidence: `clock-system-output.log`, класс `V12ClockLifecycleTest`.

После правок native-title повторены 45 Android-тестов ридера на обеих API
(`reader-after-native-api26.log`, `reader-after-native-api36.log`) и затронутые
обычные сценарии меню/первых страниц. Итоговое покрытие без повторного подсчёта
одних и тех же запусков: 17 app-сценариев API 26 и 18 API 36.
Ранние неуспешные диагностические прогоны сохранены в логах; причиной финального
повтора native-title был helper, ожидавший forward-click на задней обложке.
Финальный тест использует её доступное обратное действие и проходит.

Все логи хранятся локально в `out/qa/v1.2/logs/` и не входят в Git.

В ходе проверки исправлены также тестовые причины повторных сбоев: наблюдатель
каталога теперь читает актуальное состояние композиции; виртуализированный список
прокручивается через индекс; время удержания в тесте автопрокрутки продвигается
явно; EPUB/PDF-фикстуры очищаются и после раннего падения. Проверки целевого
переноса, сохранности книг и количества результатов импорта сохранены.

## Границы доказательств

Физические устройства по плану не использовались. AVD проверяют поведение,
адаптацию и сохранность; это не замер FPS или энергопотребления реального Fold.
Для curl сохраняется подготовка поверхности до кадра и ограниченный кэш;
проверки ридера включают raster retention и stress. Для часов отдельно проверяется
отсутствие повторной пагинации/растеризации, для кота — отсутствие анимации в фоне.

На API 36 использован программный графический backend эмулятора (`skiagl`),
чтобы обойти сбой графического транслятора среды. Итоговые прогоны и открытие
подписанного APK выполнены на этой конфигурации. Непроверенные физические
характеристики устройства не выдаются за результаты тестов.
