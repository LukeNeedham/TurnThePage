Оригинальный комплект для встроенной FB2-книги приложения. Изображения созданы
18 сентября 2026 года встроенной генерацией изображений OpenAI специально для
этого репозитория, затем уменьшены и сохранены как progressive JPEG. Внутренние
иллюстрации не содержат текста, логотипов или водяных знаков; в обложку отдельным
проходом аккуратно вписаны точные название и имя вымышленного автора.

- `seventh-light-cover.jpg` — каменный мыс и маяк на обложке;
- `seventh-light-lighthouse.jpg` — прибытие Лиды Ракитиной на маяк;
- `seventh-light-map.jpg` — старая приливная карта с седьмой отметкой;
- `seventh-light-night.jpg` — катер в штормовом фарватере.

Общее художественное задание: современная книжная иллюстрация для северной
приключенческой повести, многослойная гуашь с сдержанной линогравюрной кромкой,
холодная сине-серая палитра, графит, морская зелень и один небольшой янтарный
акцент света. Для обложки использована вертикальная композиция 2:3, для трёх
иллюстраций — горизонтальная 3:2.
