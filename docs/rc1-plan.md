# Листай 1.0.0-rc1

Утверждённый объём кандидата в 1.0 (вместо ранее планировавшейся 0.9.1).
Версия `1.0.0-rc1`, versionCode `11`, тег `v1.0.0-rc1`.

## Продукт

1. Иконка раскрытой настоящей книги: белые/голубые листы, синий твёрдый переплёт,
   заметный сгиб и толщина бумаги. Сохранить холодную палитру, убрать декоративную
   фоновую плашку. Проверить маленькие размеры и маски Android; adaptive/monochrome.
2. Библиотека прокручивается только если реальные книги не помещаются в viewport.
   Декоративные пустые ряды не должны создавать прокрутку.
3. Уменьшить толщину/глубину планок шкафа, сохранить читаемый размер обложек.
4. Настройки доступны с полки: та же бумажная вкладка, размер текста и тема,
   сохранение между запусками. Книжная навигация доступна внутри книги.
5. FB2 annotation напечатана на внутренней стороне передней обложки. Rich text,
   широкие поля, без повторения названия/автора. Длинный текст продолжается на
   ненумерованных вступительных листах, без потери текста и подмены основного прогресса.
   Без annotation — чистый форзац.
6. Вокруг закрытой книги — небольшие бумажные действия: полка, настройки,
   оглавление, закладки. Не закрывают обложку/жесты, исчезают при переходах.
   Тап по оставшейся пустой области возвращает книгу на полку.
7. Пятая иконка в верхнем поле — то же меню, что центральный тап; учитывает вырезы.
8. Одноразовые анимированные подсказки: центр → меню, жест вперёд/назад,
   тапы внешних зон → листание. Single/spread, skip/Back, DataStore, повтор из настроек.
   Демонстрация не изменяет сохранённое место чтения.

## Подготовка проекта и публикация

9. Актуализировать README, сборку/тестирование, архитектуру и release notes;
   исторические отчёты пометить как исторические. Исправить сломанные ссылки.
10. Полезный AGENTS.md и узкие проектные навыки для графики, книг/хранилища и
    существующего выпуска. Сохранить архитектурные/визуальные инварианты и границы
    разрешённых пользователем действий. Проверить навыки валидатором.
11. Оформить SourceCraft: описание, README с собственными скриншотами и демо-книгой,
    ссылка на APK, release notes с ограничениями и обратной связью; RC — pre-release.

## Приёмка

- Релевантные JVM, screenshot и instrumentation-проверки; API 26/36,
  эмуляторные phone и Fold/spread, обе темы и RU/EN.
- Библиотека: пустая, одна книга, ровно помещается, переполнение; resize и настройка темы.
- Аннотация: нет/короткая/длинная/форматированная, curl/обложка,
  оглавление, сноски, закладки, reflow и восстановление основного места.
- Онбординг: первый запуск, skip, завершение, перезапуск/поворот, повтор вручную.
- Подписанный постоянным ключом APK: чистая установка, обновление 0.9 без потери
  библиотеки/настроек/прогресса. CI для релизного коммита перед тегом и публикацией.
- Физические устройства остаются вне согласованного плана; показатели
  эмулятора не обещают аппаратного FPS.

Результаты и ограничения фиксируются в `rc1-task.md` по фактическим проверкам.
