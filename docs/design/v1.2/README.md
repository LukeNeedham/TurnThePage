# Визуальные материалы к требованиям 1.2

- `stacks-overview.png`, `stacks-gestures-fold.png` — одобренные UX-концепты
  стопок, созданные через `imagegen` по стилю существующей библиотеки Листай.
- `library-cat-reference.png` — предоставленная пользователем фотография
  кота, прообраз векторной пасхалки.
- `ibooks-title-reference.png`, `ibooks-chapter-reference.png` — предоставленные
  пользователем скриншоты iBooks, ориентиры для титула и начала главы.

Это материалы обсуждения, а не скриншоты реализованной версии Листай,
ресурсы приложения или screenshot-goldens. Фото и скриншоты референсов
сохранены без изменения. Орнаменты и кот для приложения создаются векторными.
