# Выпуск Листай в SourceCraft

Актуальная процедура выпуска находится в
[проектном навыке `listai-release`](../.agents/skills/listai-release/SKILL.md).

Репозиторий: https://sourcecraft.dev/avstaim/listai, remote `origin`, ветка `main`.
Версия берётся из `gradle.properties`. Начиная с `0.8.1` используется постоянный
release-ключ; существующий ключ нужен и для всех последующих обновлений.
Навык включает команды сборки, проверки подписи, работы с CI, тегами и релизами.
