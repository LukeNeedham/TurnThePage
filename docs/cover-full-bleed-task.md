# Обложка без цветных полей

Пользователь отклонил продолжение обложки цветом её краёв после этапа 7.2.1.

## Решение

- Оригинальное изображение занимает всю лицевую сторону: без паспарту, обрезки
  названия и второго декоративного переплёта под картинкой.
- Масштабирование по двум осям сохраняет весь исходник. Пропорции меняются:
  у обычных книжных обложек умеренно, у квадратных и широких — заметнее.
  CenterCrop не используется, поскольку может срезать название и автора.
- У корешка — слабая нейтральная тень, сверху/снизу — тонкая фаска.
  Оборот и торец — матовый графит, а не извлечённый из картинки яркий цвет.
- Полка, полёт книги и ридер используют один painter. Во время жёсткого поворота
  двигается вся печатная поверхность, без повторной подгонки картинки под угол.
- Декодер сохраняет достаточное разрешение по обеим осям, не превышая прежний
  лимит 4 194 304 пикселя. Картинка с прозрачностью печатается на белой основе.

## Проверки

- Debug и unsigned release APK собраны; `test`, `lintRelease` и `git diff --check`
  проходят.
- Все 108 скриншотных проверок проходят (96 reader + 12 library). Новые эталоны
  просмотрены: портретная обложка с названием у края, широкий исходник, полка,
  полёт, открытый переплёт, оба направления жёсткого поворота и положение ребром.
- На Android API 36, Pixel 7 emulator / `swangle`: 28 инструментальных тестов
  ридера проходят. Шесть тестов поверхности обложки проверяют полное заполнение
  разными цветовыми полосами, сохранность угловых меток, графитовый оборот,
  прозрачный исходник на белом, неизменность подготовленной поверхности и
  60 фаз поворота (3 формата × 2 темы × 2 направления × 5 положений).
- Добавлены проверки разрешения декодера по обеим осям и лимита памяти.
  Проверка синего материала учитывает фактическую непрозрачность пикселя:
  сглаженные края не дают ложных ошибок из-за unpremultiplied rounding.
- Приложение установлено и запущено на эмуляторе, вручную закрыта демо-книга
  без FB2-картинки: запасной переплёт не изменён. Screenshot:
  `/tmp/listai-cover-fullbleed-closed.png`. Crash buffer приложения пуст;
  при старте эмулятор показал диалог ожидания System UI, после ожидания работа
  продолжилась. Оригинальные картинки проверены отдельными растровыми тестами
  и preview-снимками; этот ручной снимок относится только к fallback.
