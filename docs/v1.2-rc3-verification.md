## Проверки

Полный host gate прошёл: **374 JVM-теста**, `lintRelease`, сборки debug и
instrumentation APK, **160 скриншотов ридера и 39 библиотеки**.
Команда и результат находятся в `out/qa/v1.2-rc3/logs/final-host-gate.log`:

```bash
./gradlew test lintRelease :app:assembleDebug :app:assembleDebugAndroidTest \
  :feature:reader:validateDebugScreenshotTest \
  :feature:library:validateDebugScreenshotTest
```

На **API 26 и API 36** прошли по **20 сценариев приложения**:
6 поиска/FAB, 4 операций библиотеки, 2 команд стопок, 5 реальных траекторий
перетаскивания и 3 возврата на полку. Возврат проверен с изначально невидимой
книгой, изменением числа колонок, resize во время закрытия и обратного полёта.
На каждой версии также прошли **12 проверок растровых поверхностей**:
`PhysicalAnnotationTest` (4) и `OriginalBookCoverSurfaceTest` (8).

Логи приложения: `library-ui-api26.log`, `return-and-extraction-api26.log`,
`library-return-api36.log`, `stack-trajectory-api36.log` и финальные
`stack-stable-header-api26.log` / `stack-stable-header-api36.log`.
Логи поверхностей: `reader-theme-api26.log`, `reader-theme-api36.log`,
`reader-binding-api26.log`, `reader-binding-api36.log`.

Один тест API 36 обнаружил настоящий регресс жеста: замена шапки зоной извлечения
уменьшала её высоту и могла менять scroll-host во время удержания. Ожидание конца
раскрытия в тесте не устранило сбой. После исправления шапка остаётся в layout,
зона рисуется поверх неё; геометрия полки и удерживаемой книги проверяется
отдельными assertions. Финальные **7/7 тестов стопок прошли на обеих API**.
Исходный сбой сохранён в `library-return-api36.log`, успешные повторы — в
`stack-stable-header-api*.log`.

До обновления golden просмотрены все изменившиеся рендеры. Контакт-листы:
`out/qa/v1.2-rc3/library/` и `out/qa/v1.2-rc3/reader/`.
Реальные кадры зоны извлечения, полёта и приземления в обеих темах:
`rc3-stack-extraction/`; запись — `rc3-stack-extraction.mp4`.
Промежуточные положения из видео: `extraction-video-frames/`.

На отдельном Fold-эмуляторе выполнена установка подписанного RC3 поверх RC2
через `install -r`, без удаления приложения. Сравнение в
`signed-upgrade-evidence.json` подтверждает сохранение исходника, обложки,
DataStore и всех полей базы, кроме ожидаемого `books.lastOpenedAt`, изменившегося
при холодном открытии сохранённой книги. Служебные profileinstaller-файлы
обновились. В этой библиотеке была одна книга; операции многокнижных стопок
проверены сценариями приложения с независимыми тестовыми базами.

В подписанном APK осмотрено описание в светлой/тёмной теме: бумага меняет цвет,
внутренняя обложка сохраняет свой. На Fold выполнено OPENED → CLOSED с сохранением
описания; снимки `signed-dark-description.png`, `signed-light-description.png`,
`signed-fold-closed.png`. Проверки выполнялись на эмуляторах, без физических устройств.
