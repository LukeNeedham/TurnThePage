# RC8: укладка сверху и создание стопки

Проверочная версия `1.2-rc8`, code `23`. Отдельные локальные коммиты,
без push, тегов и публикации.

## Почему RC7 не принят

В RC7 частичное рисование прежней верхней обложки поверх добавляемой книги
создавало горизонтальный разрез. Изменение progress и сохранение слоя
подтверждали наличие движения, но не физическую корректность перекрытия.
Создание новой стопки через диалог вообще не использовало фазу укладки.

## Исправление

Выбран предложенный пользователем вариант: перетаскиваемая книга ложится
сверху и становится первой в реальном порядке стопки. В течение всей
траектории её цельная обложка рисуется над существующими книгами. Маски
постепенного перекрытия удалены. Укладка занимает 560 мс; при изменении слота
собранная стопка вместе с подписью переходит к нему за 280 мс.

При перетаскивании книги на другую сохраняются обе исходные позы. Пока открыт
диалог, удерживаемая обложка остаётся на месте. После «Собрать» нижняя книга
ложится на полку, затем верхняя опускается на неё; общая фаза — 760 мс.
Порядок новой стопки: перетаскиваемая книга, затем целевая. Отмена диалога
ничего не записывает. При смене размера окна устаревшие позы отбрасываются.

Room не прерывает движение: UI сохраняет исходный каталог до конца укладки
и подтверждения согласованного членства. При создании конкретный UUID
назначается перед командой, чтобы связать результат транзакции с анимацией.
Коллизия ID отклоняется атомарно. Default добавления через меню/подборщик
остаётся прежним; `onTop=true` передаётся для анимированного drag-drop.
Undo, прогресс, закладки и частные файлы сохраняются.

## Приёмка

- Геометрия цельная и непрерывная; финальная плоскость равна статической стопке.
- Четыре цветные метки исходной обложки проверяются на реальных native PNG
  по всем углам во время движения и ожидания Room. Это обнаруживает дефект RC7,
  который не ловили проверки animation progress.
- Реальные жесты для добавления и создания: быстрое/задержанное обновление
  Room, светлая/тёмная тема, отмена, уход, прокрутка и перестановка слотов.
- Итоговая верхняя обложка соответствует первому ID в Room, в том числе после
  закрытия/открытия БД. Старые reorder/extract/menu flows проверяются повторно.
- API26/API36 и широкий Fold viewport; осмотр промежуточных кадров независимым
  агентом, host gate, подпись постоянным ключом и чистая установка APK.
