# Листай 1.0.0-rc1 — реализация и проверка

Дата приёмки: 17 сентября 2026. Версия `1.0.0-rc1`, код `11`.
Объём: [утверждённые 11 пунктов](rc1-plan.md).

## Реализовано

- Новая векторная иконка: раскрытая книга, белые листы, синий переплёт и толщина
  бумаги. Adaptive и monochrome. На Android 8 прозрачный adaptive background
  даёт чёрную маску, поэтому системная маска имеет нейтральную холодную подложку;
  деревянного фона и декоративной плитки в рисунке нет.
- Полки толщиной 8 dp. Скролл определяется реальными книгами и safe insets;
  пустые ряды заполняют только свободную видимую область и не создают прокрутку.
- Общая бумажная вкладка настроек с полки и из книги; пятая верхняя иконка
  открывает центральное меню. Настройки сохраняются в DataStore.
- Аннотация из FB2, включая форматирование, находится на внутренней передней
  обложке. Продолжение — ненумерованные листы. Позиция аннотации независима от
  основного текста; parser не сдвигает прежние block ID и закладки.
- Закрытая книга отодвигается на стол; четыре бумажных действия располагаются
  вне обложки. Во время движения они скрыты. Пустое место возвращает на полку.
- Пять шагов обучения с анимированным пальцем, реальными жестами, skip/Back,
  сохранением завершения и ручным повтором. Повтор с полки относится только
  к выбранному открытию книги, не переносится на следующую книгу.
- Room schema 3, последовательные миграции 1→2→3 без очистки библиотеки.
- README, архитектура, инструкции сборки/выпуска и release notes актуализированы.
  Добавлены собственные [скриншоты](images/README.md), AGENTS.md и проверенные
  навыки `listai-reader-ui` / `listai-books`. Существующий release skill сохранён.

## Проверки

Команды запускались с JDK 21, Android SDK 36. Для runtime созданы отдельные
чистые AVD API 26 и API 36; пользовательские устройства и данные не затрагивались.

| Проверка | Результат |
| --- | --- |
| JVM-тесты всех модулей и `lintRelease` | PASS |
| Screenshot reader + library, RU/EN, light/dark, single/spread | 135/135 PASS |
| Room/DataStore, API 36 | 7/7 PASS: v1/v2 migration, книги, закладки, исходный и annotation anchor, reopen, completion flag |
| Файловое хранилище, API 36 | 12/12 PASS |
| Нативные тесты reader, API 26 | 41/41 PASS, включая 3 новых annotation-теста |
| Подсказки и настройки полки, API 26 | 6/6 PASS, включая внешний/локальный повтор, переход к другой книге, обе обложки, annotation/TOC, пересоздание |
| Закрытая книга, API 26 | 2/2 PASS: FRONT/BACK × single/spread, жесты, отсутствие перекрытия, пустой фон, top controls |
| Регрессии сносок, навигации, импорта, Activity recreation, API 36 | 12 PASS; 2 отдельно запускаемых process-restart сценария штатно пропущены в обычном suite |
| Навыки проекта | Оба `quick_validate.py` — PASS |

Screenshot-эталоны изменены после визуальной проверки: новые верхние действия,
тонкие полки, аннотации и подсказки. Неизменные этапы не перерисовывались вручную.
Во время QA исправлены сжатая кнопка настроек полки, повтор обучения в другой
книге, восстановление аннотации, чёрная подложка launcher API 26 и контраст
подписей на бумажных действиях в тёмной теме.

## Подписанный APK и обновление

Собран `out/release/listai-1.0.0-rc1.apk`, версия `1.0.0-rc1`, код `11`.
Пакет, версия, подпись существующим постоянным ключом и zipalign проверены.
SHA-256 APK:

```text
35785a696411cb0b6d3623c970963eb490768726116a6fc15dd2a9392702bcf9
```

Именно этот файл прошёл чистую установку и холодный запуск на API 26 без
падений. На API 36 проверено обновление подписанной 0.9 через `adb install -r`
и повторный холодный запуск. Room мигрировал с 2 на 3; книга, закладка и точный
source anchor сохранены. Сравнение копии исходника по SHA-256 и DataStore
побайтно подтвердило сохранность книги, тёмной темы и выбранного размера текста.
Журнал падений пуст. Это отдельная проверка готового release APK, не debug-сборки.

Для воспроизведения сборки и host-проверок:

```bash
./gradlew --console=plain test lintRelease \
  :feature:reader:validateDebugScreenshotTest \
  :feature:library:validateDebugScreenshotTest
python3 .agents/skills/listai-release/scripts/release.py build
```

APK и отдельная контрольная сумма публикуются в
[релизе RC1](https://sourcecraft.dev/avstaim/listai/releases/v1.0.0-rc1)
после успешного SourceCraft CI для точного коммита выпуска.

## Ограничения

- RC1 — кандидат релиза, не окончательный 1.0.
- Физический обычный телефон и Fold исключены пользователем из плана проверки.
  Проверяются эмуляторные размеры, синтетический hinge и single/spread; это не
  обещание FPS или идентичного поведения каждого OEM launcher/WindowManager.
- ZIP с несколькими FB2 обрабатывается по прежнему детерминированному правилу;
  диалог выбора, верхний corner curl, backup и telemetry не добавлялись.
- Debug и release подписаны разными ключами. Нельзя удалять пользовательскую
  установку ради замены подписи: это удалит книги, прогресс и закладки.
