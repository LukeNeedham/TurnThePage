# Проверка выпуска 1.5

7 октября 2026 года. Версия `1.5`, versionCode `28`, Android 8.0+.
Тег `v1.5` закреплён на `80df6dee81c1c460c3e95f9cb5f3a8f63ee6ec01`.

## Подписанный APK

- `listai-1.5.apk`: 4 437 171 байт.
- SHA-256: `3ccae84e96784ac099c8f6761756780960fe8b30cdd0cf55ff1e26560e11e6d1`.
- Сертификат: `3a3154d0b98e97a93182f399539d03a96701c8319ec4d88833c0c23a090e81a8`.
- Неотлаживаемая release-сборка с полной оптимизацией R8 кода и ресурсов.
  Mapping и остальные отчёты сохранены в `out/release/listai-1.5-r8/<apkSHA256>/`.
- `release.py verify` подтвердил подпись, пакет, версию, выравнивание 16 КиБ
  и отсутствие debuggable. Встроенная VCS revision совпадает с тегом.
- [Опубликованный APK](https://sourcecraft.dev/api/attachments/146474820526189888)
  скачан без авторизации: размер и SHA-256 совпадают с проверенным файлом.

## Host и CI

Полный host gate прошёл: `test`, `lintRelease`, `:app:assembleDebug`,
`:feature:reader:validateDebugScreenshotTest` и
`:feature:library:validateDebugScreenshotTest`. Эталоны не менялись.
SourceCraft CI №30 для коммита выпуска успешно выполнил сборки release/benchmark
с проверкой R8, JVM-тесты, lint и screenshot validation. Отчёты mapping
сохраняются также как артефакты CI.

## Готовое приложение

Проверен именно подписанный минифицированный APK. Внешний self-instrumenting
test APK обращался к приложению через штатные ACTION_VIEW URI и accessibility,
без доступа к необфусцированным классам или базе приложения.

| Сценарий | API 26 | API 36 |
| --- | --- | --- |
| Опубликованный signed 1.1: импорт/листание/холодный запуск | PASS | PASS |
| Обновление 1.1 → signed 1.5: тот же smoke | PASS, 119,822 с | PASS, 211,043 с |
| Библиотека, страница, тёмная тема и закладка после обновления | PASS | PASS |
| FB2, EPUB, PDF; корректный PDF после повреждённого | PASS | PASS |
| FB2.ZIP через DocumentsUI, листание и восстановление | PASS | PASS |
| FileProvider и системное меню обмена | PASS | PASS |

Часы отключены в настройках; после остановки процесса и холодного запуска
на API 26 настройка сохранилась. Меню обмена закрывались без отправки файлов.
Падений приложения в crash buffers нет.

На API 36 визуально проверен разворот Fold 2208×1840/420 dpi: двухстраничное
оглавление, часть и глава справа и следующий текстовый разворот.
Точные ссылки примечаний отдельно в этом signed smoke не нажимались:
они отсутствуют как отдельные nodes в обычном UI tree. Их проверка описана
в прежней native QA; этот отчёт не расширяет её на новый APK.

Использованы чистые временные AVD: API 26 swiftshader_indirect, API 36 swangle
без Vulkan. Оба остановлены; существующие AVD и физические устройства не менялись.
Подробные логи, XML, снимки и команды сохранены в `out/qa/release-1.5/`.
