# Листай / Turn the Page 0.9

Android 8.0+ (API 26), `com.avstaim.listai`, versionCode 10.

## Изменения

- Завершён этап 9: проверки производительности, стабильности и сохранности данных.
- Исправлено падение импорта FB2 на Android API 26 при сборке на JDK 21.
- Добавлены стресс-тесты перелистывания, сносок, reflow и фонового режима;
  проверки лимита bitmap-кэша, восстановления после остановки процесса,
  прерванного импорта и удаления.
- Подготовлены недебажная benchmark-сборка, повторяемые замеры запуска и
  перелистывания, внешняя release-подпись и CI для API 26/36.
- Внешний вид книги сохранён; эталонные изображения не менялись.

## Проверки

Этап 9 проверен на версии 0.8.1/9: 263 JVM-теста, 120 визуальных проверок,
runtime-сценарии на эмуляторах API 26/36 и по пять macrobenchmark-проходов
запуска, single и spread. Для 0.9/10 повторно собраны debug/release APK и AAB,
выполнены app JVM-тесты и release lint. Полный отчёт — [этап 9](../stage9-task.md).

Ограничения: измерения эмулятора не гарантируют аппаратный FPS; проверки
физических устройств исключены из согласованного плана.

## APK

Release APK подписан существующим тестовым Android-ключом, а не ключом для
публикации в магазине. Не подходит для распространения как production-подпись.
При обновлении установленного приложения подпись должна совпадать;
удаление приложения для смены подписи удаляет его локальные книги и прогресс.
