# Листай 1.0.0-rc1

Кандидат релиза для Android 8.0+ (API 26), пакет `com.avstaim.listai`,
`versionCode = 11`.

## Что вошло в RC1

- Обновлённая иконка раскрытой книги: холодный синий переплёт, светлые листы,
  заметный корешок и adaptive/monochrome-варианты.
- Книжный шкаф с настоящими обложками и тонкими матовыми полками; прокрутка
  включается только когда реальные книги не помещаются в окно.
- Настройки доступны прямо с полки и внутри бумажной вкладки: размер текста и
  светлая, тёмная или системная тема с сохранением между запусками.
- Аннотация FB2 печатается на внутренней стороне передней обложки. Поддержаны
  rich text, широкие поля и длинные ненумерованные вступительные листы; основной
  прогресс и anchor текста остаются независимыми.
- Небольшие бумажные действия вокруг закрытой книги: полка, настройки,
  оглавление и закладки. Действия учитывают вырезы и исчезают во время переходов.
- Пятое действие в верхнем поле открывает то же меню, что и центральный тап,
  и также учитывает вырезы.
- Одноразовые подсказки для меню, жестов и внешних зон страницы с возможностью
  пропустить, повторить и продолжить после поворота или перезапуска.

Сохранены импорт FB2/FB2.ZIP, прогресс, закладки, локальная копия исходника,
русская и английская локализации, single/spread и безопасное размещение на Fold.

## Статус проверки

Пройдены JVM-тесты, release lint, 135 screenshot-проверок и сценарии на
эмуляторах API 26/36: аннотации, жёсткие обложки, подсказки, навигация, сноски,
закладки и миграция базы. Финальный подписанный APK прошёл чистую установку
на API 26 и обновление с 0.9 на API 36 с сохранением книги, позиции, закладки
и настроек. Подробности — в [отчёте RC1](https://sourcecraft.dev/avstaim/listai/browse/docs/rc1-task.md?rev=tag%3Av1.0.0-rc1).

Физические устройства исключены из согласованной приёмки. Эмуляторные результаты
не гарантируют FPS и поведение каждого OEM launcher или Fold. Это **кандидат
релиза**, не окончательная 1.0.

В [README](https://sourcecraft.dev/avstaim/listai/browse/README.md?rev=tag%3Av1.0.0-rc1)
добавлена галерея собственных скриншотов. Для разработки подготовлены AGENTS.md и
проектные навыки: renderer, книги/хранилище и выпуск. AI-инструменты относятся к
сопровождению проекта; приложение не отправляет книги в сторонние сервисы.

## Установка и обратная связь

Скачайте `listai-1.0.0-rc1.apk` из ресурсов ниже. Рядом находится контрольная сумма
`listai-1.0.0-rc1.apk.sha256`. Использован постоянный ключ Листай: подписанные
версии 0.8.1/0.9 обновляются без удаления приложения. Debug использует другой ключ;
не удаляйте пользовательскую установку ради смены подписи без сохранения данных.

Если обнаружили проблему, приложите версию Android, ориентацию/размер окна,
последовательность действий и скриншот. Для проблем FB2 достаточно небольшого
разрешённого к передаче примера, а не всей личной библиотеки.
