# Листай 1.2-rc2

Второй кандидат исправляет управление библиотекой и делает работу со стопками
понятнее.

- При перетаскивании на другую книгу она остаётся на месте. Короткое удержание
  собирает стопку; второй палец отменяет объединение без перестановки книг.
- Создание стопки через меню теперь занимает один экран: название и выбор книг
  с миниатюрами обложек. Исходная книга уже выбрана, название предлагается
  автоматически и редактируется. Кнопка создания показывает количество книг
  и остаётся доступна при открытой клавиатуре.
- Меню книги и стопки открываются на бумажной нижней карточке: обложка, название,
  автор или количество книг, крупные действия с иконками. Удаление и разбор
  стопки отделены от остальных действий.
- Уточнены расположение книг на полках, подписи и вид стопок. При раскрытии
  книги разворачиваются из положения стопки; у открытой стопки есть собственное
  меню.
- Поиск получил отдельные действия очистки и закрытия. «Готово» скрывает
  клавиатуру, сохраняя результаты. Back сначала убирает клавиатуру, затем
  закрывает поиск и возвращает к исходной полке или стопке без лишнего нажатия.

Все остальные возможности 1.2 сохраняются. Поиск по-прежнему работает только
в библиотеке.

Версия APK: `1.2-rc2`, код `17`; подпись прежним постоянным ключом.
Подписанное обновление поверх RC1 проверено с сохранением данных библиотеки.
Это локальный кандидат для проверки; push, теги и публикация не выполнялись.

Результаты: [проверка RC2](../v1.2-rc2-verification.md).
