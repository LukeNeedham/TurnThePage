# Листай 1.0.0-rc2

Предрелизная сборка `versionCode = 12`.

## Исправления

- Закрытая обложка на широком/Fold viewport больше не растягивается на весь
  экран: масштаб ограничен книжной пропорцией и не вмешивается в определение
  hinge или выбор single/spread.
- Внутренняя передняя обложка снова использует материал жёсткой обложки.
  Аннотация FB2 печатается на ней светлыми чернилами; если аннотация длинная,
  продолжение на следующих листах остаётся обычной бумагой.
- Launcher icon возвращает узнаваемый вертикальный силуэт исходной Листай,
  сохраняя сине-серую палитру, твёрдый переплёт и поддержку adaptive/themed icon.

## Область проверки

Проверяются unit/screenshot-тесты затронутых модулей и host gate проекта.
Физические телефоны и Fold в этот кандидат не входят. Фото пользователя —
исходная диагностика дефектов, а не результат тестирования RC2 на железе.

## Установка

Скачайте `listai-1.0.0-rc2.apk` и соседний файл контрольной суммы со страницы
[релиза RC2](https://sourcecraft.dev/avstaim/listai/releases/v1.0.0-rc2).
Сборка подписана постоянным ключом Листай и обновляет RC1/0.9 без удаления данных.
