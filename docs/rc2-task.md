# RC2 — приёмка

## Цель

Проверить два исправления и визуальную полировку релиза `1.0.0-rc2`
(`versionCode = 12`):

1. В закрытой позе обложка сохраняет книжную пропорцию на широком и Fold-like
   viewport и не растягивается на весь экран. Выбор hinge-safe layout остаётся
   прежним.
2. Внутренняя передняя обложка рисуется материалом обложки, а FB2-аннотация —
   светлыми чернилами. Overflow аннотации рисуется на бумажных листах.
3. Launcher icon снова использует компактный вертикальный знак настоящей книги
   и фирменный синий фон, не теряя adaptive и monochrome варианты.

## Проверки

- JVM-тесты масштабирования закрытой книги и рендеринга annotation surfaces —
  пройдены.
- Screenshot validation для закрытой обложки и внутренней аннотации — пройдена;
  изменённые эталоны осмотрены до принятия.
- На API 36 эмуляторе пройдены точный synthetic Fold-сценарий закрытой обложки
  и все три `PhysicalAnnotationTest` для материала, чернил и overflow.
- Финальный подписанный APK установлен начисто и запущен холодным стартом; затем
  отдельно проверено обновление подписанного RC1 на RC2 через `adb install -r`.
  После обоих запусков crash buffer пуст, установлены `versionName = 1.0.0-rc2`
  и `versionCode = 12`.
- Новая иконка собрана как обычный, adaptive и monochrome resource и визуально
  проверена в системном launcher под круглой маской.
- Полный host gate пройден:

  ```text
  ./gradlew test lintRelease :app:assembleDebug \
    :feature:reader:validateDebugScreenshotTest \
    :feature:library:validateDebugScreenshotTest
  ```

Физические устройства исключены из текущего плана. Длинный исторический тест,
который делает серию системных скриншотов, дважды завершил headless AVD аварией
графического backend (`SIGSEGV`); кодового падения приложения в доступных логах
не было. RC2-проверки выше после этого повторены точечно на стабильном API 36 AVD.
