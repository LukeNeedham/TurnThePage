# Листай 1.2-rc11 — части без пустых остановок на телефоне

Локальная проверочная сборка `1.2-rc11`, code `26`, ветка `codex/v1.2`.
Push, теги и публикация не выполнялись.

## Изменение

Проекция частей добавляла пустые листы для начала справа и чистого оборота
шмуцтитула в обоих режимах. Теперь она создаёт такие листы только в `SPREAD`.
В `SINGLE` после титула части одним перелистыванием открывается глава,
обратное листание также не останавливается на пустом листе. Убрано и пустое
выравнивание перед эпилогом книги с частями.

Сам титул части и все фрагменты эпиграфа сохраняются, в том числе продолжения
при крупном шрифте. Номера в одностраничном режиме идут подряд. Смена режима
сохраняет исходный `BookLocation`; в развороте остаются пустой оборот слева
и нечётная страница главы справа. PDF и исходный текст не менялись.

## Воспроизведение и проверки

До исправления новые JVM-проверки падали: четыре проверки пагинации и одна
проверка позиции. Native-тест на прежнем APK воспроизвёл остановку на пустом
листе одним свайпом после «Части второй» встроенной книги «Седьмой огонь».
Артефакты: `out/qa/v1.2-rc11/jvm-before-fix/`,
`logs/blank-single-before-fix.log`, `logs/native-before-fix.log`.

- Полный `test lintRelease :app:assembleDebug :app:assembleDebugAndroidTest`:
  **PASS**, 1m41s, **438 JVM-тестов**, failures/errors/skipped — 0;
  Debug/Release не суммировались повторно.
- API26, 1080×1920: **6/6 native PASS**, 35.070s. Части в обоих режимах,
  обратное листание, складывание/раскладывание, возврат из примечаний,
  вход в эпилог. Скриншоты просмотрены, системная подсказка закрыта перед запуском.
- API36, 1080×2400: **2/2 native PASS**, 21.980s — часть и эпилог.
- API36, 2208×1840: **5/5 native PASS**, 49.917s — части, смена режима,
  оглавление и возврат из примечаний.

В первых API36 debug-снимках осталась системная подсказка полноэкранного режима;
эти кадры не используются как окончательное визуальное подтверждение.
Для окончательной проверки используется чистая установка подписанного APK.

Первая проверка скриншотов: 173/176 reader совпали, три телефонных эталона
отличались только краями блока листов: без пустых страниц изменилось соотношение
прочитанной и оставшейся толщины. До обновления просмотрены исходники,
новые кадры и diff; внутренний прямоугольник страницы совпадает пиксель в пиксель.
Обновлены только `PartOpeningPhone`, `PartOpeningDarkPhone`, `PartLongTitle`.
Все три Fold-эталона частей и остальные эталоны сохранены. Доказательства
осмотра: `out/qa/v1.2-rc11/screenshot-review/`.

Повторный полный screenshot gate: **PASS**, 2m40s. Reader **176/176** выполнены
заново; library **60/60** из актуального результата `UP-TO-DATE`.
Host renderer и native-съёмка запускались последовательно.
