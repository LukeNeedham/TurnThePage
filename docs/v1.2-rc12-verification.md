# Листай 1.2-rc12 — титул справа в развороте

Локальная проверочная сборка `1.2-rc12`, code `27`, ветка `codex/v1.2`.
Push, теги и публикация не выполнялись.

## Исправление

Раньше перед титулом был только разрыв страницы: после нечётного количества
листов описания титул попадал слева, а оглавление — справа от него.
Теперь общая пагинация служебных страниц проверяет физическую сторону начала
титула. В `SPREAD` перед левым титулом добавляется ровно один пустой лист.
Если титул уже справа, вставки нет. После титула пустой оборот не добавляется.
В `SINGLE` выравнивание вообще не создаёт листов, как и выравнивание частей.

Обрабатывается только начало титула. Длинный заголовок и авторы сохраняют
все исходные символы и продолжаются без дополнительных вставок. Пустой лист
привязан к адресу следующего титула; поиск по адресу выбирает страницу с текстом.
Основной прогресс, описание и титул остаются независимыми. PDF не менялся.
