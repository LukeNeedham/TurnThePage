# Листай 1.2-rc2 — исправления библиотеки и проверка

Дата: 2026-09-28. Версия `1.2-rc2`, versionCode `17`, ветка `codex/v1.2`.
Итоговый production-код: `23bafab`; последующий коммит `979ed7f` содержит
проверки и осмотренные эталоны. Базовый объём и предыдущие проверки описаны
в [отчёте RC1](v1.2-verification.md); этот документ фиксирует изменения RC2.

в этом исправлении не менялись.

## Автоматические проверки

Полный host gate прошёл: **367 JVM-тестов, 158 скриншотов ридера,
39 скриншотов библиотеки**, `lintRelease`, сборка debug-приложения и
instrumentation APK. Итог: `BUILD SUCCESSFUL` в
`out/qa/v1.2-rc2/logs/final-host-gate.log`.

Базовая команда проверки:

```bash
./gradlew test lintRelease :app:assembleDebug :app:assembleDebugAndroidTest \
  :feature:reader:validateDebugScreenshotTest \
  :feature:library:validateDebugScreenshotTest
```

Финальная instrumentation-приёмка: **17 тестов на API 26 и 17 на API 36,
все прошли**. Логи: `final-acceptance-api26.log` и
`final-acceptance-api36.log` в `out/qa/v1.2-rc2/logs/`.
Покрыты поиск и возврат в стопку, очистка/Done/Back с реальной клавиатурой,
создание стопки за одно подтверждение с реальным Room, переименование,
добавление/извлечение/перенос, разбор и Undo, перетаскивание и автопрокрутка,
pinch/pull, доступные действия, импорт и остановка кота.

Два теста `V12StackTrajectoryTest` сначала воспроизвели дефекты на старом RC1:
соседняя книга уезжала при входе на её край, а удержание без новых движений
не показывало готовность объединения. Оба завершились ошибкой в
`trajectory-rc1-baseline.log`, затем прошли в финальных прогонах RC2.
Тест ведёт палец по реальной траектории, проверяет границы цели и отмену
вторым пальцем.

Новые визуальные сценарии включают карточки книги/стопки, создание и добавление
книг, ширину 320 dp с fontScale 1.5, Fold, RU/EN и обе темы. Эталоны обновлены
после осмотра намеренных изменений. В подписанном APK вручную осмотрены меню
книги и стопки, единый лист создания и компактная шапка. Создана стопка
из двух импортированных FB2. Записаны и осмотрены промежуточные кадры
раскрытия и обратной сборки; пустых поверхностей книги не было.
Evidence: `signed-fold-book-menu.png`, `signed-fold-picker.png`,
`signed-fold-stack-menu.png`, `signed-stack-motion.mp4`, `motion-contact-0.jpg`
в `out/qa/v1.2-rc2/`.

Проверено настоящее переключение Fold OPENED→CLOSED: открытая стопка
сохранилась, обе книги и подписи доступны, шапка и нижние действия не
перекрывают их. Снимки: `signed-fold-open-stack.png`, `signed-fold-closed.png`.

## Подписанное обновление

На Fold AVD проверена установка подписанного RC2 поверх подписанного RC1
через `install -r`. Сравнение до/после в
`out/qa/v1.2-rc2/signed-upgrade-evidence.json` подтвердило:

- строки всех таблиц SQLite совпали (`books`, `bookmarks`, `book_stacks`,
  `android_metadata`, `room_master_table`);
- исходник книги, обложка и DataStore совпали по SHA-256;
- изменились только служебные файлы `profileInstalled` и
  `profileinstaller_profileWrittenFor_lastUpdateTime.dat`.

Дополнительно в подписанной сборке вручную импортированы две FB2 через
системный выбор файлов. Системный отчёт подтвердил: добавлено 2, ошибок 0; обе книги затем
выбраны и объединены в стопку (см. `signed-fold-picker.png`).
