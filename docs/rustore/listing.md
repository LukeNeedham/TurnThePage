Подготовлено 23 сентября 2026 года для `com.avstaim.listai`,
`versionName = 1.0`, `versionCode = 14`, Android 8.0+ (API 26).
Тексты ниже предназначены для первой публикации. Наличие этого файла
не означает, что приложение уже загружено или прошло модерацию RuStore.

## Краткое описание

```text
Читайте FB2 как бумажную книгу: перелистывание, закладки и разворот на Fold.
```

## Полное описание

```text
Листай — читалка FB2 с ощущением бумажной книги. Выберите книгу с полки,
откройте обложку и перелистывайте страницы. Управление находится на книжных
вкладках и не отвлекает от текста.

На телефоне книга занимает экран одной страницей. На Fold и широком экране
доступен двустраничный разворот. Приложение подстраивает текст под размер окна
и сохраняет место чтения.

Возможности:
• импорт книг в форматах FB2 и FB2.ZIP;
• книжная полка с обложками;
• перелистывание страниц и жёсткая обложка;
• книжная гарнитура «Плёс» и настройка размера текста;
• светлая, тёмная и системная темы;
• оглавление, аннотация, иллюстрации и сноски с возвратом к тексту;
• цветные закладки и переход к нужному месту книги;
• сохранение прогресса и настроек между запусками;
• русский и английский интерфейс.

Для знакомства уже добавлена демонстрационная книга. Собственные книги
можно выбрать через системное окно файлов или открыть из другого приложения.
Листай сохраняет частную копию: удаление книги с полки не удаляет исходный файл.

Приложение работает без интернета, рекламы, аккаунтов и телеметрии. Книги,
закладки и настройки остаются на устройстве. Облачной синхронизации нет.

Для работы нужен Android 8.0 или новее. Поддерживаются FB2 и FB2.ZIP;
форматы EPUB и PDF в этой версии не поддерживаются.
```

## Данные и разрешения

Release-манифест 1.0 не содержит `android.permission.INTERNET`, разрешений
камеры, микрофона, геолокации, контактов или общего доступа к хранилищу.
Есть внутреннее signature-разрешение AndroidX
`com.avstaim.listai.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`.

Приложение локально обрабатывает выбранные файлы, метаданные книг, прогресс
и закладки; передачи за пределы устройства код не выполняет. При заполнении
«Безопасности данных» нужно сверить формулировки актуальной формы: если она
спрашивает о доступе к файлам, отразить «Файлы и документы» и локальный импорт;
не заявлять отсутствие доступа к пользовательским файлам. Аналитику,
рекламу, идентификацию пользователя и передачу данных приложение не выполняет.
RuStore требует проверить автоматически заполненные типы данных и дополнить
их по фактическому поведению приложения.
[Описание декларации](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/how-to-declare-permissions),
[категории данных](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/data-categories).

Техническое основание для privacy.md: `app/src/main/AndroidManifest.xml`,
release merged manifest, `ListaiApplication`, `ListaiApp`, `LibraryController`,
`PrivateBookStorage`, `LibraryRepository`, `LibraryDatabase`, `AppPreferences`
и состав зависимостей Gradle. Не обещать шифрование собственной базой
приложения или гарантированное отсутствие переноса средствами производителя:
таких механизмов и гарантий в коде нет.

## APK и изображения

Использовать тот же подписанный `listai-1.0.apk`, что опубликован в SourceCraft.
Проверить пакет, версию, контрольную сумму и постоянную подпись. Подписанный APK
принимается напрямую; для этой загрузки AAB не требуется.

- Иконка: PNG/JPG, 512×512, сплошной фон; целевой размер до 1 МБ.
  Готовый файл — `out/rustore/1.0/icon-512.png`, исходник действующей
  иконки — `app/src/main/res/drawable/ic_launcher.xml`.
- Скриншоты: минимум 3 для каждого выбранного типа устройств; PNG/JPG,
  телефон до 3 МБ, планшет до 5 МБ, максимальное разрешение 2160×3840.
  Подготовить свежие кадры 1.0 в 9:16 (например, 1080×1920) или 16:9.
  Можно загрузить только телефонные кадры — они будут показаны и на планшетах.
- Показывать реальные полку, чтение, оглавление/вкладку; без системных панелей
  Android. Проверить результат кадрирования в Console.

[Инструкция публикации](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication)
указывает для иконки лимит 3 МБ, а
[требования к приложениям](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps)
— 1 МБ; размер до 1 МБ удовлетворяет обоим документам. Скриншоты RC1 из
`docs/images` имеют другие пропорции и не должны подменять свежие материалы 1.0.

## Первая загрузка и последующие обновления

1. Войти в [RuStore Console](https://console.rustore.ru/) через VK ID.
   При необходимости зарегистрировать аккаунт разработчика. Для физлица
   доступ открывается после подтверждения данных; для ЮЛ/ИП требуется УКЭП
   и проверка 2–4 рабочих дня.
   [Физлица](https://www.rustore.ru/help/developers/developer-account/registration-developer/registration-fl),
   [ЮЛ/ИП](https://www.rustore.ru/help/developers/developer-account/registration-developer/registration).
2. С ролью владельца добавить приложение «Листай», загрузить APK и дождаться
   обработки. Заполнить карточку, данные, контакты и материалы. Сохранённые
   обработанные файлы без отправки на модерацию хранятся 14 дней.
   [Процедура первой публикации](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication).
3. Отправить версию на модерацию. Для исполнения запроса на выпуск выбрать
   автоматическую публикацию. После одобрения она занимает до часа;
   ручной режим потребует кнопки «Опубликовать» после статуса «Готова к публикации».
   [Режимы публикации](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/setting-up-publication/instant-app-publishing).
4. Проверить публичную карточку и доступность установки. Ожидание модерации
   не считать состоявшейся публикацией.

Public API не создаёт первую активную версию: метод создания черновика требует
уже существующую активную версию этого приложения. После первой публикации
можно автоматизировать обновления: токен → черновик → APK и изображения →
модерация → проверка статуса/публикация.
[Ограничение создания черновика](https://www.rustore.ru/help/work-with-rustore-api/api-upload-publication-app/create-draft-version),
[API-процедура](https://www.rustore.ru/help/work-with-rustore-api/api-upload-publication-app).
