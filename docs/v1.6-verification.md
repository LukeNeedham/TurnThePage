## Готовая минифицированная сборка

Проверен именно APK с SHA-256 выше на отдельных эмуляторах Android 8.0/API 26
и Android 16/API 36. Физические устройства в эту проверку не входят.

| Сценарий | API 26 | API 36 |
| --- | --- | --- |
| Чистая установка, холодный запуск, первый шаг обучения, Next и Skip | PASS | PASS |
| Обновление подписанной установки с сохранением текста, позиции, закладки и темы | PASS | PASS |
| Минифицированный FB2/EPUB/PDF smoke, перелистывание и восстановление после force-stop | PASS | PASS |
| Отклонение повреждённого PDF с последующим импортом правильного | PASS | PASS |
| Pinch: размер текста, временное увеличение, перемещение, возврат и отключение | PASS | PASS |
| Back закрывает настройки с сохранением увеличения; следующий Back возвращает масштаб | PASS | PASS |
| Crash buffer после проверок | Пустой | Пустой |

ZIP/обмен через FileProvider и отклонение зашифрованного PDF проверены ранее
в этой же серии изменений; финальный APK дополнительно прошёл обновление и
восстановление чтения. Для API 36 внешний тест переведён на современный
AndroidJUnitRunner: старый runner использовал удалённый Android test API.
Ожидания закрытия вкладки учитывают асинхронное обновление accessibility;
код приложения и APK при адаптации теста не менялись.

Отчёт именно финального APK:
`out/qa/release-1.6/164a91b76afbf8c2/qa-summary.json`.
Чистые AVD остановлены, данные исходных проверочных библиотек сохранены.
